# Home Automation Git Deployer

Home Assistant app repository for the Home Automation Git Deployer.

Add this repository to the Home Assistant App Store:

`https://github.com/uberswimmer/home-assistant-git-deployer`

The application safely deploys allowlisted Home Assistant YAML from a separate Git repository using read-only SSH access, local-drift detection, Home Assistant configuration validation, and automatic rollback on failed validation.
